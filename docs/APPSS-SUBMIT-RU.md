## Как подать

1. Откройте [@appss](https://t.me/appss) в Telegram
2. Нажмите **Start** / меню → раздел для разработчиков (**Add app** / **Submit** / **My Apps** — формулировка может отличаться)
3. Либо зайдите на [appss.pro](https://appss.pro) → **Login** → **My Apps** → **New App**
4. Вставьте ссылку `t.me/бот/farm`, описания выше, загрузите скриншоты
5. Укажите категорию **Games**

Если в @appss нет пункта подачи — напишите в Support чат каталога (кнопка Support на appss.pro) с текстом:

```
Здравствуйте! Прошу добавить Mini App в каталог.

Название: Farm Builder
Ссылка: https://t.me/BOT_USERNAME/farm
Категория: Games / Simulation
Описание: фермерский idle-симулятор в Telegram Mini App
Контакт: @your_username
```

## Скриншоты — что снять

1. Экран `/start` с кнопкой «ЗАПУСТИТЬ ФЕРМУ»
2. Mini App — вид фермы (canvas)
3. Сообщение «Урожай готов!»
4. Баланс после сбора урожая
5. (Опционально) построенный склад

На Windows: Win+Shift+S или запись экрана телефона через «Повтор экрана» в Telegram Desktop.
